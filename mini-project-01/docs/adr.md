### 의사결정 ① 입력 특성 선택 (CP-02)

**문제**

예측 시점에 사용할 수 없거나 누수가 발생할 수 있는 특성이 있습니다.

- **검토한 선택지:** "yr" 포함 여부, "atemp" 제거 여부, "windspeed" 제거 여부, "casual" 및 "registered" 제거 여부
 (예: `casual`·`registered` 포함 여부, `atemp` 포함 여부, `windspeed` 제거 여부)
- **최종 선택(사용·제외한 특성):** "yr", "hr", "workingday", "weathersit", "temp", "hum"
- **선택 근거(누수 확인, 예측 시점, 상관관계 등):** "casual", "registered" : 누수 확인 / "windspeed" : 낮은 상관관계
- **감수한 한계 또는 추후 확인할 점:** "yr": 연도에 따른 대여량 증가는 보이나 2년 데이터로 명확한 증가량 포착이 어렵고, 적은 데이터(11년, 12년), 데이터 분할로 인해 대여량과 상관관계는 더욱 줄어듬. 

**분석 근거:** `01_regression_data_analysis.md`

### 의사결정 ② 최종 회귀 모델 선택 (CP-07)

**문제**

서로 다른 회귀 모델 및 설정 중 하나를 최종 모델로 선택해야 합니다.

- **비교한 모델·설정:** DecisionTree (depth=12, leaf=5) / RandomForest (A)
- **최종 선택한 모델·설정:** DecisionTree (depth=12, leaf=5)
- **선택 근거(Validation MAE, 과대적합 가능성, 시간대별 오류 등):** 랜덤포레스트 대비 시간대별 MAE가 다수 구간에서 낮으며, 전반적인 검증 성능을 고려했을 때 결정트리가 더 적합하다고 판단함.
- **선택 모델의 장점:** 모델 구조가 비교적 단순하여 해석이 용이하고, 시간대별 대여량 패턴과 주요 특성의 관계를 직관적으로 파악할 수 있음.
- **남아 있는 한계 또는 개선 방향:** 출퇴근 및 퇴근 시간대(17~19시)과 관련된 특성을 추가했음에도 상대적으로 큰 오차가 발생하므로, 해당 시간대의 대여량 변동을 설명할 수 있는 추가 특성 발굴이 필요함.

## 2일차 — 분류 (온라인 쇼핑 구매 여부 예측 · PyTorch MLP)

### 의사결정 ③ 평가 지표 선택 (CP-04)

**문제**

구매 세션이 전체의 약 15%뿐인 불균형 데이터이므로, Accuracy만으로 구매 클래스를 얼마나 잘 예측하는지 판단하기 어렵습니다.

- **검토한 선택지:** F1-Score (예: Accuracy, 구매 클래스 F1, Precision, Recall)
- **최종 선택한 주 지표와 보조 지표:** F1-Score / Recall, Precision
- **선택 근거(DummyClassifier와 LogisticRegression 결과, FP·FN 등):** 
  로지스틱 회귀 모델의 혼동 행렬을 검토 해보았을 때, 기준 모델과 달리 입력에 대해 구매자로 예측한 143건 발생하였으며, 실제 구매자 중 미구매자로 예측한 값(FN, 181건)이 해결해야할 과제로 남아있지만, 미구매자를 구매자로 오인(FP, 38건)하게 된 수에 비해 구매자를 제대로 예측한 값(TP, 105건)으로 상승하였음에 기인하여 더미 모델 대비 성능 향상을 확인 할 수 있고, 프로젝트의 데이터에서 소수인 타겟(구매자)을 정확히 예측하기 위해 구매자를 정확히 예측한 비율인 Recall과 구매자로 예측한 결과 중 구매자 비율인 Precision 모두 중요한 지표이나 이 두 지표 모두를 고려한 F1-Score가 중요함(구매자 예측이 중요하여 모두 구매자로 예측하면 구매자에 대한 예측 정확도는 상승하겠지만 더미 모델과 다를바 없음).

- **감수한 한계 또는 추후 확인할 점:**
각종 지표들의 검토 결과 학습 검증 간의 성능 지표의 차이(f1 기준, 0.5 / 0.49)가 크지 않았고, 이는 모델이 잘 학습된 것으로 보임. 다만, 모델의 복잡도가 낮아 데이터의 특징들을 충분히 학습하지 못한 것으로 보임. 따라서 보다 복잡한 모델 채용으로 모델 일반화 성능의 향상을 기대 할 수 있을 것으로 보이며 특히 Recall 값이 Precision에 비해 유독 낮게 나타는 것과 혼동행렬 분석 결과, 구매자를 미구매자로 예측한 케이스가 다수 확인되었으며, 이 부분아 모델의 일반화 성능 향상을 위한 주요 해결 과제임.

**분석 근거:** `02_classification_data_analysis.md`, `02_classification_model_analysis.md`

### 의사결정 ④ PyTorch MLP 설정 및 분류 임계값 선택 (CP-07)

**문제**

기본 손실 함수로 학습한 MLP-A와 클래스 가중 손실을 적용한 MLP-B를 비교하고, 구매 확률을 0/1로 구분하는 임계값(0.3·0.5·0.7)을 선택해야 합니다.

- **검토한 선택지:** MLP-A(th=0.3·0.5·0.7) / MLP-B(th=0.3·0.5·0.7)
- **최종 선택한 MLP 설정·임계값·재학습 에포크:** MLP-B(weighted BCE) Threshold=0.5, Epoch: 17
- **선택 근거(Validation F1, Precision·Recall, FP·FN 및 가중 손실의 영향):**
MLP-A, MLP-B 두 모델을 예측 임계값(0.3, 0.5, 0.7) 별로 실험하고, 성능 지표 중 F1-Score를 주 결정 요인으로 선택하였으며
보조 결정 요인으로 Recall, Precision을 참고하여 최종 모델을 선택하였음(둘 중 Recall에 조금 더 중점을 둠).

F1-Score(0.625)가 가장 높게 나온 모델과 유사(0.02 차이)하며 Precision(0.639)와 Recall(0.6129)의 차이가 적은 MLP-B(th=0.7)와 가장 뛰어난 F1-Score(0.645)와 더불어 Precision(0.575)과 Recall(0.734)의 차이는 크지만 Recall의 성능이 우수한 MLP-B(th=0.5)를 최종 모델의 후보로 고려하였으며, 최종적으로 종합성능(F1-Score)이 가장 뛰어나며 실제 구매자 중 구매자로 예측한 비율(Recall)이 본 프로젝트에서 더 중요하다고 판단하여 MLP-B(weighted BCE, th=0.5)를 최종 모델로 선정하였음.

- **LogisticRegression과 비교했을 때 선택한 MLP의 특징:**
  로지스틱 회귀 대비 Precision의 감소(0.734 > 0.575)하였고, Recall에서 유의미한 상승(0.367 > 0.734)이 관측되었음.
  이는 선택한 MLP-B(weighted BCE, th=0.5) 모델에 양성 클래스 가중치를 적용한 영향으로 보이며, 구매자를 보다 공격적으로 탐색하게 되어 놓치는 구매자가 감소(FN 수치 감소)하고, 미구매자를 구매자로 오인하는 경향이 증가(FP 수치 증가)한 것임.
  F1-Score 또한 유의미한 상승(0.49 > 0.645)을 보여 일반화 성능이 크게 상승함.
- **감수한 한계 또는 추후 개선 방향:**
실험한 모델 중 MLP-B(weighted BCE, th=0.5)가 가장 우수한 F1-Score(0.645)를 기록하였으나, 해당 수치만으로 모델의 일반화 성능이 충분히 확보되었다고 판단하기는 어려움. 또한 로지스틱 회귀 모델 대비 Recall은 크게 향상되었지만 Precision이 감소하여, 구매자를 더 많이 탐색하는 과정에서 미구매자를 구매자로 오인하는 경우(FP)가 증가하는 한계가 존재함.
추후 개선 방향으로는 모델의 Depth를 조정하여 모델의 표현력을 높이면서, Dropout 및 정규화 등을 활용하여 과적합을 방지하는 방향을 고려할 수 있음. 또한 학습률, 배치 크기, 클래스 가중치 등의 하이퍼파라미터 보다 폭 넓게 실험하고 최적화하여 모델의 일반화 성능 향상과 Precision과 Recall의 균형을 개선할 필요가 있음.
